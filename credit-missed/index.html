    三类各怎么单独分析　判据不同，方法就不能共用

    A · 修复后再恶化（411 家 / 1.80 万亿）

    要回答的问题：这是"二次冲击的开头"，还是最后一天的估值噪声。

    怎么做：① 看末段斜率——11/06 单日 vs 最后三日累计，只有单日跳的当噪声剔除； ② 叠加成交——有成交笔数配合 = 真抛压，无成交 = 估值补跌； ③ 叠加到期结构——未来 3 个月到期占比高的，恶化会直接变成再融资压力。

    需要的数据：逐券成交笔数/偏离、债券到期现金流（DM bond_cash_flow）

    B · 信用事件异动（48 家 / 0.71 万亿）

    要回答的问题：相对于同类型主体，它的估值被打出了多少超额，还会不会继续。

    怎么做：不用修复率。以舆情日为事件日，算相对同（大类×期限×等级）中位曲线的 累计异常 bp，看异常是否还在扩大；再核评级变动、担保变化、司法/被执行信息，判断是"情绪定价"还是"基本面定价"。

    需要的数据：事件日历、bond_guarantee_info、company_judicial_case_info、公司评级

    C · 超调（212 家 / 11.75 万亿）

    要回答的问题：修复率 >100% 是真买盘，还是低流动性券的估值跳动。

    怎么做：按流动性分层——高流动性 + 有成交 = 真抢筹；低流动性 / 私募定向无成交 = 估值回摆， 不能算进"市场已修复"。这直接决定对外汇报时余额口径的修复率该不该打折。

    需要的数据：DM 流动性评分、成交笔数、双边报价

    打标规则（互斥，按优先级）　① 信用事件异动 = 主体内有券个性成分 >20bp；② 未受冲击 = 中位最大回撤 <3bp； ③ 超调 = 中位修复率 >100%；④ 单边恶化 = ≥5/6 日上行且净上行（上一版 268 家，其中 22 家因①②③优先级更高被归到别处，故此处 246）； ⑤ 修复后再恶化 = 净上行 >0 且 11/05→11/06 仍上行，但中间修复过；⑥ 正常修复 = 其余。 口径　主体级指标取该主体存续券的中位数；余额为发行人余额按券数摊分。 ⚠️ 同一条限制　A 类里私募债 + 定向工具占比 —，这类券成交稀疏、中债估值调整滞后， "末端再上行"有相当一部分是补跌，必须回到成交确认后才能当信号用。 脚本　analyze_missed.py → _missed.json → build_missed_html.py。
